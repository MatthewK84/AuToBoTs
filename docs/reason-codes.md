# Reason codes

Indication, log, and spec use the same strings.

| Code | Meaning |
| --- | --- |
| fence | Fence not ok |
| fix | Fix stale |
| link | Link stale |
| heartbeat | Flight-controller heartbeat stale |
| weak_track | Weak track inside commit range |
| energy | Endurance does not exceed time-to-rally |
| estimator | Estimator-ok bit false |
| grant_time | Grant path refused or latched |
| pilot_override | Pilot override active |
| abort | Abort requested or phase Abort |
| coast | Coast quality not ok |
| no_grant | No valid grant |
